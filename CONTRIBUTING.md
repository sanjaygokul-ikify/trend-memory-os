# Contributing to Memory-OS
We welcome contributions to any level of the memory architecture. Good first issues are tagged `good-first-issue`.

## Contribution Guidelines
- All architecture changes require an RFC
- Follow the existing folder structure
- Add benchmarks for performance changes
- Ensure new features are covered by tests

## Development Workflow
1. Fork the repo
2. Create a feature branch
3. Add tests
4. Submit PR with changelog snippet

## Communication
Join our Discord for architecture discussions. All design decisions must be documented RFCs in the `docs/rfcs/` directory.
